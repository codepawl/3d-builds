# Prompts

The original prompt is still missing. The seal was built in a Codex session. The Codex session files were removed from this machine when the Codex CLI was dropped, and a search of the Claude Code transcripts (typed messages and agent briefs, with the words seal, trumpet, squeeze and the project name) found no copy.

What the project notes (`src/README.md`) say the request asked for:

- A plump seal that you can stretch with a mouse or a finger.
- A pull or a change of direction plays the next trumpet note of a song, one note for each stroke.
- The tune loops, and staying still for three seconds starts it over.
- Controls to give or remove the trumpet, mute the sound and restart the song.
- Original geometry and synthesized audio. No image generation, no downloaded model, no recorded soundtrack.
- A Three.js version and a 67.js version that share the same model, deformation and audio.
- Checks for the note order, looping, reset, one note per stroke, touch input, audio and a 320 px layout.
