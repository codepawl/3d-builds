# Shirayu Onsen vs Hakugin Onsen: onsen

Two builds of the same scene brief, one by Claude Opus 5.5 and one by Gemini 4 Argon, each made in Blender and rendered live in three.js. Scene: an outdoor hot spring beside a wooden ryokan in snowy mountains, with steam and falling snow.

- Post: https://x.com/anxuanng/status/2110854613192880221
- Made with: Claude Opus 5.5 in Claude Code (`claude -p --model opus`) for `src/opus`, Gemini 4 Argon (`agy --model gemini-4-argon-high`) for `src/argon`, three.js 0.180.0, Blender 5.2

## How it was made

1. Both models got the same two files as the brief, `design/COMMON.md` and `design/onsen.md`. Each ran headless once from a one-line prompt, with no hand edits.
2. Each model wrote Blender Python scripts that model every asset procedurally, then exported GLB files. No downloaded models, textures or HDRIs.
3. Each model wrote a three.js app with the same toolbar, controls, four time-of-day presets and a `window.battle` recording hook.
4. Pass 1 time (wall clock): Opus 54.8 min, Argon 49.1 min. These numbers come from the runner logs.
5. After the owner watched both builds side by side, both models got a second pass. It asked for a more realistic scene and one shared camera look, `src/shared/battle-look.js`. It also carried a feedback file for each model. Total time with pass 2: Opus 106 min, Argon 107 min.
6. Both builds were filmed by the same recorder script through the `window.battle` hook (20 s, 1920x1080, 30 fps). The side-by-side video was assembled separately and is not in this repo.


## Run it

Each build is its own npm project with three.js pinned to 0.180.0. For Opus, from this folder:

```
npm --prefix src/opus install
npm --prefix src/opus run serve
```

The Opus server uses port 5505. Open http://localhost:5505. The built assets are in `src/opus/assets` or `src/opus/public/assets`. To rebuild them, install Blender 5.2 and run `npm --prefix src/opus run assets` (or `build:assets`, see its `package.json`).
For Argon, run `npm --prefix src/argon install`, then `npm --prefix src/argon run serve`. `src/argon/README.md` lists its asset scripts.
Use `?capture=1` for the recording mode. Keys: drag to look, mouse wheel to walk the path, `1` to `4` for presets, `F` for depth of field, `C` for the DSLR look.

## Design

`design/onsen.md` is the scene: place, mood, four preset names and the camera path. `design/COMMON.md` is the method, the UI and the recording hook. `design/PASS2.md` and the two feedback files are the second pass. `design/battle-run-notes.md` has the timings of all four battle scenes.
Both builds use the same shared look: 4x MSAA, ambient occlusion, bloom, depth of field, vignette, grain and handheld sway, at a fixed 50 degree field of view. The scene itself is each model's own work.
`poster.jpg` is a frame of the Opus pass 2 build.

## Assets and credits

All models and textures are generated by the Blender scripts in each build. Nothing is downloaded. three.js is installed from npm (MIT).
`src/shared/battle-look.js` is the shared camera and post-processing module, written for these battles.
GLB files over 20 MB are not in this repo. Rebuild them with the Blender scripts.
