# team_truck - paddock race transporter (EU cab-over tractor + box semi-trailer)

## Dimensions
| Item | Value | Source |
|---|---|---|
| Combination length | 16.5 m max | Wikipedia "Semi-trailer truck" extract (EU limit) |
| Trailer length | 13.6 m | same (standard EU semi-trailer) |
| Height | 4.0 m | EU Directive 96/53/EC (extract notes 4.2-4.4 m in some states) |
| Width | 2.55 m | EU Directive 96/53/EC |
| Tractor wheelbase | 3.8 m | typical 4x2 cab-over tractor spec sheets (numbers only) |

## Parts
Cab with windscreen, visor, mirrors, grille, lights; chassis, tanks, fifth wheel; trailer box with skirts, rear doors,
tri-axle bogie, landing legs, marker lights. Wheels are separate objects.
