# SPDR: steampunk spider

A mechanical steampunk spider with an editable Blender model and procedural leg animation in three.js. It walks over an obstacle course, climbs, jumps and vents steam.

- Post: https://x.com/anxuanng/status/2108652663252685226
- Made with: Astra in Codex, three.js, esbuild, Blender 5.2 (the model script is `src/blender/build_spider.py`)

## How it was made

1. The owner asked for a mechanical spider in the style of a reference image, scary and massive, with steam. The words are in `prompts.md`. The original prompt message was not kept.
2. Astra modelled the spider in Blender and exported `assets/spider.glb`. The editable file is `assets/spider.blend`.
3. It built the procedural walk in three.js, with planted feet, stepping and body motion. The owner pointed it at a public animation talk on procedural animation by t3ssel8r (https://www.youtube.com/watch?v=KPoeNZZ6H4s).
4. Later revisions added a darker environment, hanging hoses with Verlet chains, a jump with spring landing, synthesized footstep sound and a pixel mode. `src/README.md` describes them.
5. The post shows a screen recording of the interactive page. I do not know how many rounds of fixes it took. The project notes do not record the run time.

## Run it

You need Node.js. three.js and esbuild come from one folder where you ran `npm install three esbuild`. Set `JS67_DIR` to that folder first, for example `export JS67_DIR=/path/to/67.js`. `src/server.mjs`, `src/build.mjs` and the tests read it. The recording and smoke scripts also need Playwright (`npm install playwright`). Then, from this folder:

```
node src/server.mjs
node --test src/motion.test.mjs src/strand-physics.test.mjs
node src/smoke.mjs
node src/build.mjs
```

The preview uses port 5186. `build.mjs` writes a static site to `dist`. To rebuild the model, run `blender --background --python src/blender/build_spider.py` with Blender 5.2.
Controls: move the pointer to lead the spider, arrow keys move the target, right-drag to orbit, scroll to zoom, Space vents steam. The Terrain and Pixel toggles switch the obstacle course and the pixel look.

## Design

The model has six legs in the style of the reference: an armoured body, glowing amber eyes, brass pipes and thin multi-jointed legs. The gait steps each foot when it drifts from its home position.
`design/MOTION-REFERENCES.md` lists the jump studies behind the jump animation. `src/README.md` describes the environment, hoses, jump and sound.
`poster.jpg` is a frame of a jump.
