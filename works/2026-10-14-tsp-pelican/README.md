# Pelican on a bike, drawn as one line

A pelican riding a bike drawn as a single line through 16,384 dots, then lifted into 3D where it pedals. Every frame is drawn in JavaScript on a 2D canvas, and the music is synthesized in code.

- Post: https://x.com/anxuanng/status/2110487420731007461
- Made with: Claude Opus 5.5 in Claude Code, Node.js, headless Chromium (Playwright), ffmpeg

## How it was made

1. The task was a 60 second film in the spirit of a Fourier epicycle pelican video, but with different mathematics: travelling salesman (TSP) art. The brief is in `design/BRIEF.md` and `prompts.md`.
2. The subject is an original line drawing in `src/pelican.mjs`, rendered to a density field.
3. `src/compute.mjs` places points with weighted Lloyd relaxation for 5 stages of N, builds a tour, and untangles it with 2-opt until no segments cross. The data goes to `src/data/`.
4. `src/film.mjs` draws any frame from that data. `src/record.mjs` renders frames in headless Chromium, and `src/encode.ps1` runs ffmpeg.
5. A second part lifts the same line into 3D and pedals it (`src/pose.mjs`, `design/pelican-on-bike.md`).
6. The score comes from `src/score.mjs`. The run took about 112 minutes by its timestamps (19:40 to 21:32 UTC). I could not find the follow-up prompts that changed the subject from a fox to the pelican.

## Run it

You need Node.js and Playwright (`npm install playwright`). Set the Playwright path in `src/browser.mjs` if needed. From this folder:

```
node src/compute.mjs
node src/record.mjs stills 12.6
```

`compute.mjs` rebuilds the data (the shipped `src/data/` already holds the result). `record.mjs stills <seconds>` writes single frames. `record.mjs frames <first> <last>` writes frames at 30 fps, and `src/encode.ps1` joins them with the score into an mp4 (needs ffmpeg).

## Design

Dark navy sky, glowing cyan line with bloom, gold for crossings and highlights, serif math type. Stages N = 64, 256, 1024, 4096, 16384 each show dots, the raw tour, 2-opt untangling the crossings, then a pen point that redraws the final line. The readout shows N, crossings and length from the real run.
`poster.jpg` is the final drawing.
