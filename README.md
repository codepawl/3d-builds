<h1 align="center">3d-builds</h1>

The source, prompts and design notes behind the 3D pieces posted on [@anxuanng](https://x.com/anxuanng). Each folder under `works/` matches one post, or a few posts about the same build. Most of them were built by Claude Opus 5.5 in Claude Code with the [visualize-in-3d skill (viz3d)](https://github.com/codepawl/viz3d).

Each folder has:

- `README.md`: what it is, the post, how it was made and how to run it. It also gives the design choices and the asset credits.
- `prompts.md`: the prompts in order, translated to English where they were written in Vietnamese. Where the original prompt was not kept, the file says so.
- `design/`: the plan files the agent worked from, such as topic files, briefs, look notes and review notes.
- `src/`: the code: three.js apps, film recorders, Blender scripts and sound scripts.
- `poster.jpg`: one still.

Videos, downloaded music, other people's reference media and assets without a licence to share are left out. Each README says what is missing and where to get it.
